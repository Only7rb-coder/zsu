# ZSU 1.4.10 — Navigation and update reliability

Nested screens now keep the bottom tab that owns them selected. Settings children such as Customization, Developer, Disguise, and App Profile Templates select **Settings** instead of falling back to **Home**. Module repository, meta-module, addon, superuser, SU log, app-profile, and module-action screens select **Manage**. The stock installer remains associated with **Home**. Ambiguous screens such as Backup/Restore retain the originating root tab through the navigation back stack.

Module updates are now failure-safe. Download filenames are sanitized before passing them to Android DownloadManager, malformed or unsupported URLs are rejected without throwing through the UI coroutine, callback delivery is marshalled to the main thread, and the update listener tracks only its own download rather than every DownloadManager completion. Update exceptions and download failures now show a localized error instead of terminating ZSU.

The build retains the 1.4.9 bottom-dock fix, directional tab animations, and Home header without the CONTROL CENTER subtitle. No kernel, root, module execution, or automatic reboot behavior changes are included.
