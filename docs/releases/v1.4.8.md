# ZSU 1.4.8 — Crimson

## New

- **Install / Update SUSFS LKM** button in Addons, matching the existing one-tap installers.
- Resolves the latest stable release from `matsuzaka-yuki/susfs-lkm-module` on every press and selects only the `arm64-multi-kmi.zip` asset. The same button installs the loader or updates an existing installation.
- Downloads and installs through the existing KernelSU addon workflow with progress and installer output. **Reboot is required** after installation or update. The loader's own installer performs device/KMI compatibility checks.

## Design

- New geometric crimson Z-shield logo, adaptive launcher icon, monochrome themed icon, and legacy launcher density assets.
- Black-and-crimson UI: near-black layered surfaces, warm neutral text, red accents, and a polished dashboard/navigation treatment.
- Dark appearance is the default; the reusable theme still supports explicit light, dynamic-color, and AMOLED overrides.
- Dark Android startup background to avoid a white flash before the UI loads.

## Maintenance

- Safely quote paths passed to the addon module installer.
- Clean up addon ZIP downloads in a `finally` block, including failed download/install attempts.
- Align APK versionName with release tag `1.4.8` and raise versionCode for upgrades over the previous release.

## Downloads

- Normal manager APK: standard ZSU package identity.
- Spoofed manager APK: existing alternate package identity.

There is **no toggle, background updater, automatic reboot, or change to the kernel/root execution logic** in this release. To fetch a later SUSFS loader release, press its Addons button again.
