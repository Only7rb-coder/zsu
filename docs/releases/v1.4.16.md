# ZSU v1.4.16

This maintenance release refreshes ZSU’s KernelSU-Next compatibility layer while preserving ZSU’s custom manager identity, GhostLock integration, and spoofed-manager packaging.

## Changes

- Applied the latest compatible KernelSU-Next SELinux status-hook cleanup to avoid taking the SELinux status lock in the open hook.
- Bumped the manager version to `1.4.16` with a higher installable version code.
- Kept ZSU-specific manager and kernel integrations intact; upstream BakaSU features that require a different kernel/userspace layout were not force-merged.

## Build artifacts

The release workflow produces both the normal and spoofed ZSU manager APKs.
