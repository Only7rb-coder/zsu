# ZSU 1.4.9 — Navigation polish

The crimson bottom dock now has an opaque surface and a background scrim, preventing page content from showing through behind the tab icons. System navigation and display-cutout insets are applied outside the dock; the inner Material3 NavigationBar no longer consumes them inside a fixed-height layout. All four tabs have consistent icon sizes and visible labels, with a subtle scale animation on selection.

Tab changes now slide and fade according to their order: moving right enters from the right, moving left enters from the left. The same transition applies to tab taps, horizontal swipes, and Back-to-Home, while nested routes use a lightweight fade. Scroll-hide state resets after navigation so the new screen does not inherit a hidden dock.

The Home header shows the logo and **ZSU** only; the **CONTROL CENTER** subtitle has been removed. Manage content is now scrollable, and both Manage and BL Root reserve bottom space so their last controls can be reached above the dock.

This build retains the SUSFS LKM one-tap install/update button and black-and-crimson theme from 1.4.8. No kernel or root-execution behavior changes are included.
